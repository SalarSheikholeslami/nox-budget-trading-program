
## Data

### Required Data Files

The analyses build on the replication materials associated with Curtis (2018), together with additional electricity-price data from the U.S. Energy Information Administration (EIA).

The Stata scripts require the following input files:

| File | Used in | Description |
|------|---------|-------------|
| `cbp_st_table2.dta` | MEA1, MEA2, TCA | State-industry employment data |
| `stfueldata09_figureO4.dta` | MEA1, MEA2, TCA | Supporting data used in the original empirical framework |
| `HS861 1990-2009.xlsx` | TCA | Additional EIA industrial electricity-price data |

### Access to the Data

The first two datasets are associated with the original replication materials for:

Curtis, E. M. (2018). *Who Loses under Cap-and-Trade Programs? The Labor Market Effects of the NOx Budget Trading Program.* The Review of Economics and Statistics, 100(1), 151–166.

[Original published article – MIT Press](https://direct.mit.edu/rest/article/100/1/151/58423/Who-Loses-under-Cap-and-Trade-Programs-The-Labor)

Readers should consult the original replication or supplementary materials for access to these datasets.

The EIA Form 861 Excel file is an additional dataset used for the electricity-price-channel extension and must be obtained separately.
